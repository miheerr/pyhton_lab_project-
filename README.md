"# pyhton_lab_project-" 
Menu-Driven Program in Python

This project is a Menu-Driven Application developed using Python that provides users with an interactive and user-friendly interface to perform multiple operations through a single program. The application displays a list of options in the form of a menu, allowing users to select the desired functionality by entering the corresponding choice.

The program is designed using conditional statements, loops, and functions to ensure smooth navigation and efficient execution of tasks. It continuously runs until the user chooses to exit, making it easy to perform multiple operations without restarting the application. The project demonstrates core Python programming concepts such as user input handling, decision-making, modular programming, and error handling.

This project enhances problem-solving skills and provides practical experience in designing structured and interactive command-line applications. It serves as a strong foundation for developing more advanced software systems with multiple functionalities.
